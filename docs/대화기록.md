# Talk Buddy 개발 대화 기록

2026-10-25, Claude Code(Claude Fable 5.1)와 함께 만든 과정을 요청 순서대로 정리한 기록입니다.
다른 컴퓨터에서 이어서 개발할 때 "왜 이렇게 되어 있는지"를 빠르게 파악하는 용도입니다.
기술 구조와 규칙은 `CLAUDE.md`, 사용법은 `README.md`에 있습니다.

## 1. 첫 요청: 초등 5학년 영어 회화 앱

**요청**: 일상 상황을 최대한 많이, 카테고리별로 나누고, "카페에서 주문하기"처럼 상황을 정해 AI와 롤플레이하는 챗봇. OpenAI API 활용. 하루·일주일·한 달 기간별 대화 기록 확인.

**결정과 결과**
- 설치 없이 쓰도록 순수 HTML/CSS/JS 웹앱으로 결정. API 키는 사용자가 설정에 직접 입력(브라우저에만 저장).
- 카테고리 12개 × 상황 84개 (`js/scenarios.js`). 상황마다 AI 역할, 미션 3개, 유용한 표현 4개, 첫 대사.
- 롤플레이 프롬프트: 짧고 쉬운 영어, 항상 질문으로 끝내기, 미션 달성 시 `[[MISSION:n]]`, 실수 시 한국어 `[[TIP: ...]]` 태그 → 앱이 파싱해 체크 표시와 "선생님 팁" 표시.
- 도움 기능: 한국어 뜻 보기, "뭐라고 말할까?"(추천 문장 3개), 유용한 표현, TTS 자동 읽기, 마이크 입력.
- 대화 종료 시 AI 리포트(별점, 칭찬, 더 좋은 표현, 배운 단어, 다음 팁).
- 기록: 하루/일주일/한 달/전체 탭, 통계 타일, 막대그래프, 대화 목록(내용 다시 보기), 연속 학습 일수.
- API 키가 없으면 데모 모드(고정 대사)로 흐름 체험 가능.

## 2. 폴더 이동 + 휴대폰 앱

**요청**: `E:\프로그램 제작\회화` 폴더로 옮기고 휴대폰 앱으로도 쓰게.

**결과**: PWA로 전환. `manifest.webmanifest`, `sw.js`(앱 파일 캐시, OpenAI 요청은 가로채지 않음), 아이콘 5종(Python PIL로 생성), 홈 화면 설치 카드.
휴대폰 설치와 마이크는 https가 필요하므로 호스팅 방법을 README에 정리.

## 3. GitHub Pages 배포

**요청**: GitHub Pages에 올려 휴대폰에서 열 수 있는 주소 만들기.

**과정**: 이 PC에 git과 gh가 없어 winget으로 설치(관리자 승인 필요했음) → `gh auth login` 브라우저 기기 코드 로그인(계정 jeedan81) → 공개 저장소 `talk-buddy` 생성·푸시 → Pages를 main 브랜치 루트로 활성화.

**결과**: https://jeedan81.github.io/talk-buddy/ 배포. 이후 모든 변경은 `git push`만으로 반영.

## 4. API 키 안내

OpenAI 플랫폼(platform.openai.com → API keys)에서 발급, 결제 수단 등록과 소액 충전 필요, 사용 한도 설정 권장. gpt-4o-mini 기준 대화 1회 1~2원 수준. 보호자가 키 관리 권장.

## 5. 일본어 버전

**요청**: 일본어 버전 포함.

**결정과 결과**
- 설정 `lang: 'en' | 'ja'`. 홈·상황 창·설정에서 전환.
- 84개 상황 전부 일본어 제목·역할·표현·첫 대사 추가(`js/scenarios_ja.js`). 한국어 뜻은 영어 표현과 같은 순서라 재사용.
- **초등 일본어는 한자 없이 히라가나·가타카나 + 띄어쓰기** 규칙. AI 프롬프트에도 동일 규칙.
- TTS/STT 언어 전환, 기록에 언어 필터와 국기 표시.
- 서비스워커 캐시 v2.

## 6. 중등·고등·일반 단계

**요청**: 중등, 고등, 일반으로 구분해 영어·일본어 모두.

**결정과 결과**
- 설정 `stage: elem | middle | high | adult`. 단계마다 전용 상황 세트: 중등 30, 고등 30, 일반 30 (각 카테고리 10개). 초등은 기존 84개.
- 팩 등록 방식: `registerStagePack(stage, {categories, scenarios})` (`js/scenarios_middle.js` 등). 상황 객체 안에 `ja:{}` 포함.
- 단계별 AI 규칙(`api.js` `STAGE_RULES`): 문장 길이, 어휘 수준(영어 A1→C1, 일본어 N5→N2), 일본어 한자 사용 정도와 경어, 교정 개수, 리포트 말투.
- 일본어 중등 이상에서 "뜻 보기"는 히라가나 읽기 + 뜻 두 줄로 반환.
- 고등·일반 단계는 홈 인사말을 존댓말로. 기록에 단계 필터. 총 상황 174개. 캐시 v3.

## 7. 게임 기능

**요청**: 흥미를 높이는 게임들, 단어·문장·문법 학습.

**결정과 결과**
- 하단 메뉴에 게임 탭. 7종: 단어 카드(뒤집기, 아는 단어 저장), 단어 퀴즈(4지선다), 빈칸 채우기(예문), 문장 조립(상황 표현을 조각으로), 짝 맞추기(시간·실수 점수), 듣고 받아쓰기(TTS), 문법 챌린지(설명 포함).
- 재료는 현재 언어·단계: 상황 표현 + 새 데이터 `js/vocab.js`(단어 단계×언어 25개 = 200개, 문법 10문제 = 80개).
- XP/레벨(100 XP당 1레벨), 하루 50 XP 목표, 배지 8종, 대화 1회 완료 = 10 XP. 진행도는 `talkbuddy.progress`에 저장, 내보내기/가져오기에 포함.
- 기록 화면에 게임 횟수·XP 통계. 캐시 v4.
- 일본어 중등 이상 문장 조립은 형태소 분석기가 없어 문장부호 + 글자 수 기준 조각(퍼즐 느낌).

## 8. 화면 단순화 + 캐릭터

**요청**: 화면이 복잡하니 간단하게, 아이콘·캐릭터로 직관적으로.

**결정과 결과**
- 마스코트 "버디"(주황 말풍선 SVG, 표정 happy/cheer/think/sad)를 `app.js`의 `mascot()`로 그려 홈·결과·게임·미션 완료에 사용.
- 홈: 캐릭터 인사 헤더 + 큰 버튼 3개(대화하기/게임하기/내 기록) + 상태 한 줄 + 오늘의 추천 1개(하루 고정) + 카테고리 아이콘. 언어·단계 토글은 "바꾸기" 칩 하나 → 선택 시트.
- 채팅: AI 말풍선에 역할 아바타, 미션 칩 줄 → 한 줄 진행(🎯 1/3 ●○○ 다음: …), 도구 4개 → 💡 힌트·📖 표현 2개, 듣기/뜻 버튼은 아이콘만.
- 게임 허브: 레벨·목표 카드 하나 + 아이콘 카드, 최근 기록 제거. 기록 통계 타일 8 → 4. 설치 안내는 설정 화면으로 이동. 캐시 v5.

## 반복해서 겪은 문제와 해결

- **배포 직후 404**: GitHub Pages CDN 전파로 새 파일이 1~2분간 404. 기다리면 해결. 너무 일찍 요청하면 404가 잠시 캐시됨.
- **옛 화면이 계속 보임**: 서비스워커 + 브라우저 캐시(max-age 600). `sw.js` CACHE 버전을 올리고, 급하면 캐시 삭제 후 새로고침.
- **Windows PowerShell에서 gh --jq**: 식 안에 큰따옴표가 있으면 인자가 쪼개져 "accepts 1 arg(s), received 2". 작은따옴표만 쓰거나 파일로.
- **긴 커밋 메시지**: PowerShell에서는 here-string을 파일로 저장한 뒤 `git commit -F 파일`.

## 다른 컴퓨터에서 이어서 하기

1. git 설치 후 `git clone https://github.com/jeedan81/talk-buddy.git` (수정·푸시하려면 GitHub 계정 jeedan81 로그인: `gh auth login` 또는 Git 자격 증명 관리자).
2. Claude Code에서 그 폴더를 열면 `CLAUDE.md`가 자동으로 읽힙니다. 이 문서를 함께 보여 주며 "이어서 ○○ 기능을 추가해 줘"라고 요청하면 됩니다.
3. 로컬 확인: `python -m http.server 8766 --directory <폴더>` 후 브라우저에서 열기. API 키 없이도 데모 모드로 확인 가능.
4. 수정 후 `git add -A; git commit -m "..."; git push` → 1~2분 뒤 배포. `sw.js` 캐시 버전 올리는 것 잊지 말기.

# 🗣️ Talk Buddy – 초등 5학년 상황별 영어·일본어 회화 파트너

"카페에서 주문하기", "길 물어보기"처럼 일상 속 상황을 골라 AI와 **영어 또는 일본어**로 롤플레이하는 웹앱입니다.
설치 없이 브라우저에서 바로 실행되고, OpenAI API로 대화합니다.

- 홈 화면·상황 선택 창·설정에서 🇺🇸 영어 / 🇯🇵 일본어를 언제든 바꿀 수 있어요. 모든 상황이 두 언어를 지원합니다.
- **학습 단계** 4가지: 🧒 초등(84개 상황) · 🎒 중등(30개) · 🎓 고등(30개) · 💼 일반(30개). 단계마다 상황 세트와 AI의 난이도(문장 길이, 어휘, 경어, 일본어 한자 사용)가 달라집니다.
- 일본어는 초등은 **한자 없이 히라가나·가타카나 + 띄어쓰기**, 중등부터는 단계에 맞는 한자를 쓰고 "뜻 보기"에서 **히라가나 읽기**를 함께 보여 줍니다. 음성 읽기·마이크도 일본어로 전환됩니다.
- 기록은 언어별·단계별로 구분해서 볼 수 있어요.

| 단계 | 대상 | 영어 | 일본어 | 상황 예시 |
|---|---|---|---|---|
| 🧒 초등 | 초등학생 | A1~A2, 1~2문장 | N5 이하, 가나만 | 카페 주문, 길 묻기, 친구 사귀기 |
| 🎒 중등 | 중학생 | A2~B1, 2~3문장 | N5~N4, 기본 한자 | 발표 준비, SNS 규칙, 홈스테이, 중고 거래 |
| 🎓 고등 | 고등학생 | B1~B2, 3~4문장 | N4~N3, 일반 한자·정중어 | 교환학생 면접, 토론, 호스텔 문제, 은행 계좌 |
| 💼 일반 | 성인 | B2~C1, 자연스러운 성인 회화 | N3~N2, 비즈니스 경어 | 명함 교환, 연봉 협상, 불만 응대, 임대 계약 |

## 실행 방법

1. 이 폴더에서 간단한 웹 서버를 켭니다. (아래 중 하나)
   ```bash
   python -m http.server 8765
   ```
   ```bash
   npx serve .
   ```
2. 브라우저에서 `http://localhost:8765` 를 엽니다. (Chrome / Edge 권장 – 음성 인식 지원)
3. **설정 → API 키**에 OpenAI API 키(`sk-...`)를 넣고 저장 → "연결 테스트"로 확인합니다.
   - 키는 이 브라우저의 `localStorage`에만 저장되고, OpenAI 서버로만 전송됩니다.
   - 키가 없으면 **데모 모드**(고정 대사)로 화면 흐름만 체험할 수 있습니다.

> `index.html`을 더블클릭해 `file://`로 열어도 동작합니다. 다만 마이크(음성 인식)는 `http://localhost` 또는 `https`에서만 됩니다.

## 📱 휴대폰에서 앱처럼 쓰기 (PWA)

이 앱은 PWA(설치형 웹앱)입니다. 인터넷 주소로 한 번 열면 휴대폰 홈 화면에 아이콘으로 설치되고, 전체 화면으로 열립니다. 앱 파일은 기기에 캐시되어 다음부터 빠르게 뜹니다. (대화에는 인터넷이 필요해요.)

### 1단계 – 휴대폰에서 열 수 있는 주소 만들기

휴대폰 설치와 마이크 기능은 **https 주소**가 필요합니다. 무료로 올리는 방법 중 하나를 고르세요.

| 방법 | 하는 법 | 특징 |
|---|---|---|
| **Netlify Drop** (가장 쉬움) | https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 | 1분 안에 `https://xxx.netlify.app` 주소 생성, 회원가입 필요 |
| **GitHub Pages** | 이 폴더를 GitHub 저장소에 올리고 Settings → Pages → Branch `main` / root | `https://아이디.github.io/저장소명/` |
| **Cloudflare Pages / Vercel** | 폴더 업로드 또는 저장소 연결 | 위와 비슷 |
| 같은 Wi-Fi에서 PC로 서비스 | PC에서 `python -m http.server 8765` 실행 후 휴대폰 브라우저로 `http://PC의IP:8765` 접속 | 간단하지만 http라서 **홈 화면 설치·마이크는 안 됨**, 타이핑 대화는 가능 |

> 업로드할 파일: `index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/` (README와 `.claude` 폴더는 없어도 됩니다)

### 2단계 – 홈 화면에 설치하기

- **Android (Chrome)**: 주소를 열면 홈 화면에 "📱 휴대폰에 앱으로 설치하기" 카드가 뜹니다 → **설치**. 또는 Chrome 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**.
- **iPhone / iPad (Safari)**: 아래 **공유(⬆)** 버튼 → **홈 화면에 추가**. (iOS는 Safari에서만 설치할 수 있어요.)
- **PC (Chrome / Edge)**: 주소창 오른쪽의 설치 아이콘(⊕)을 누르면 데스크톱 앱처럼 설치됩니다.

설치 후 설정에서 API 키를 한 번만 넣으면 그 기기에 저장됩니다. 기기마다 따로 입력해야 하며, 기록도 기기별로 저장됩니다(설정 → 내보내기/가져오기로 옮길 수 있어요).

## 주요 기능

| 기능 | 설명 |
|---|---|
| 상황별 롤플레이 | 12개 카테고리 · 84개 상황. AI가 점원/선생님/친구 역할을 맡아 짧고 쉬운 영어로 대화 |
| 미션 3개 | 상황마다 미션(예: 음료 주문하기, 가격 묻기)이 있고, 달성하면 자동 체크 ✅ |
| 선생님 팁 | 문법/표현 실수가 있으면 한국어로 짧게 알려 줌 (혼내지 않고 자연스럽게) |
| 도움 기능 | 🇰🇷 뜻 보기(한국어 번역) · 💡 뭐라고 말할까?(추천 문장 3개) · 📖 유용한 표현 |
| 듣기 / 말하기 | AI 대사 자동 읽기(TTS), 🎤 마이크로 영어 말하기 입력(STT) |
| 결과 리포트 | 대화 종료 시 별점, 칭찬, 더 좋은 표현, 오늘 배운 단어, 다음 연습 팁 |
| 기록 | **하루 / 일주일 / 한 달 / 전체** 탭. 대화 횟수, 말한 문장 수, 공부 시간, 완료 상황, 미션, 별, 게임 횟수·XP + 막대그래프 + 대화 목록(대화 내용 다시 보기) |
| 🎮 게임 | 7가지 미니게임으로 단어·문장·문법을 익혀요 (API 키 없이 동작). 아래 표 참고 |
| XP · 배지 | 게임과 대화로 XP를 모아 레벨업, 하루 50 XP 목표, 배지 8종 |

### 🎮 게임 종류

| 게임 | 익히는 것 | 방법 | XP |
|---|---|---|---|
| 🃏 단어 카드 | 단어 | 카드를 뒤집어 뜻·예문 확인, "알아요/아직"으로 분류 (모르는 단어가 먼저 나와요) | 카드당 최대 2 |
| 🔤 단어 퀴즈 | 단어 | 뜻 ↔ 단어 4지선다 10문제 | 정답당 3 |
| ✏️ 빈칸 채우기 | 단어·문장 | 예문의 빈칸에 맞는 단어 고르기 | 정답당 3 |
| 🧩 문장 조립 | 문장 | 상황별 표현을 조각으로 섞어 순서대로 조립 | 정답당 5 |
| ⚡ 짝 맞추기 | 문장 | 표현 6개와 뜻을 연결, 시간·실수에 따라 점수 | 최대 25 |
| 👂 듣고 받아쓰기 | 듣기·문장 | 음성을 듣고 그대로 입력 (천천히 듣기 지원) | 정답당 5 |
| 📝 문법 챌린지 | 문법 | 단계별 문법 10문제, 정답 후 한국어 설명 | 정답당 4 |

| 기타 | 연속 학습 일수(🔥), 이어서 하기, 기록 내보내기/가져오기(JSON) |

## 파일 구조

```
index.html          화면 뼈대 (+ 서비스 워커 등록)
manifest.webmanifest PWA 설치 정보 (앱 이름, 아이콘, 색)
sw.js               서비스 워커 (앱 파일 캐시, 오프라인 화면)
icons/              앱 아이콘 (192/512/maskable/apple-touch)
css/style.css       스타일
js/scenarios.js     카테고리/상황 데이터 (여기에 상황을 추가하면 바로 반영) + 언어 목록/localize()
js/scenarios_ja.js  초등 상황의 일본어 버전 (상황 id별 제목·역할·표현·첫 대사)
js/scenarios_middle.js  중등 단계 팩 (카테고리 10 + 상황 30, 영어·일본어 포함)
js/scenarios_high.js    고등 단계 팩 (카테고리 10 + 상황 30)
js/scenarios_adult.js   일반 단계 팩 (카테고리 10 + 상황 30)
js/storage.js       localStorage 저장(설정, 대화 기록)
js/api.js           OpenAI Chat Completions 호출, 프롬프트, 데모 모드
js/vocab.js         게임용 단어장(VOCAB)과 문법 문제(GRAMMAR)
js/games.js         미니게임 7종, XP/레벨/배지
js/app.js           화면 렌더링과 앱 로직
```

## 상황 추가하기

`js/scenarios.js`의 `SCENARIOS` 배열에 객체를 하나 추가하면 됩니다.

```js
{ id: 'my-scene', cat: 'food', emoji: '🍩', title: '도넛 가게에서', en: 'At the Donut Shop', level: 1,
  place: 'a donut shop', ai: 'Amy, a shop worker', user: 'a customer',
  situation: '도넛 가게에서 좋아하는 도넛을 골라 보세요.',
  missions: ['도넛 종류 묻기', '두 개 고르기', '가격 묻기'],
  phrases: [['What kinds of donuts do you have?', '어떤 도넛이 있어요?'], ['Two chocolate donuts, please.', '초콜릿 도넛 두 개 주세요.']],
  opener: "Hi! Welcome to Donut House. What would you like?" }
```

중등·고등·일반 단계는 각 팩 파일의 `scenarios` 배열에 추가하며, 일본어 버전은 상황 객체 안에 `ja: { title, ai, phrases, opener }`로 함께 넣습니다. 초등 상황의 일본어 버전은 `js/scenarios_ja.js`에 같은 id로 추가합니다. (없으면 그 상황은 영어로만 나와요.)

```js
'my-scene': { title: 'ドーナツやさんで', ai: 'エミ（てんいん）',
  phrases: ['どんな ドーナツが ありますか？', 'チョコドーナツを ふたつ ください。'],
  opener: 'いらっしゃいませ！ドーナツハウスへ ようこそ。なにに しますか？' },
```
